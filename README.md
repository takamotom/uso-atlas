# うそアトラス (uso-atlas)

Neo ATLAS簡略版のWebゲーム。日本から船を派遣して隠された世界地図を少しずつ発見していく。

**キモ**: 船長の報告は真実（現実の地球の地形）とは限らない。歪んだ海岸線、存在しない島、消えた大陸——報告を「信じる」か「信じない」かはあなた次第。信じた報告だけが世界地図として確定するので、あえて嘘を信じ続ければ荒唐無稽な世界地図を作れる。

## 遊び方

1. 点線で囲まれた海域をクリックして船を派遣する
2. 船長が持ち帰った報告（赤い破線の地形）を見て「信じる」か「信じない」を選ぶ
3. 信じると地形が確定し、隣の海域へ進めるようになる。信じないと同じ海域に再派遣でき、別の報告が出る
4. 全72海域を確定させると世界地図の完成。PNGで保存できる

### 船長

雇う船長は3人（HUDのセレクタで選択。確定地形の再現に関わるため、替えると新しい航海になる）。

- **実直な船長**: 報告はほぼ真実。歪みも小さい
- **気まぐれな船長**: ほどよく嘘が混じる
- **夢見る船長**: 真実は4回に1回。ムー大陸級の捏造大陸や大陸盤が浮上し、「沈没」で大陸ごと消える報告も出る

### 世界のかたち

世界が球体か平面かは最初は誰も知らない。東西の果てを跨ぐ航海を試みると船長が「世界の果て」の報告を持ち帰り、それを信じるかどうかで確定する。

- **滝の報告を信じる** → 平面世界。果ては越えられず、地図の縁に滝が現れる
- **海が続くという報告を信じる** → 球体世界。地球一周が可能に
- 果てを確かめないまま完成させると、世界のかたちは謎のまま終わる

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run test       # Vitest
npm run lint       # ESLint
npm run build      # 型チェック + 本番ビルド
npm run preprocess # 地図データ再生成（scripts/ne_110m_land.geojson → src/assets/world-regions.json）
```

開発用ギャラリー（報告のバリエーション確認）: `http://localhost:5173/uso-atlas/#gallery`

### 仕組み

- 真実の地形は Natural Earth 1:110m（パブリックドメイン）を日本中心（中央経線150°E）のequirectangularに前処理し、経度30°×緯度30°の72海域にクリップ済み
- 報告は `(海域ID, 試行回数, ホラ吹きレベル)` をシードに決定的に生成。嘘=歪み・捏造・消失/沈没の組み合わせ。レベルごとのパラメータは `src/report/config.ts` の `INTENSITY_PRESETS` に集約
- すべての嘘変換はセル境界帯では恒等変換なので、どの報告を信じても隣接海域と海岸線が繋がる（「沈没」も境界帯の残骸を残すことでこの保証を守る）
- セーブはシード+履歴方式（localStorage、数KB）。生成アルゴリズムやプリセット変更時は `game/save.ts` の `SAVE_VERSION` を上げる

## ライセンス

地図データ: [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）
